## 🎮 使用方法

### 启动程序
```bash
python tv_rename_gui_v1.3.py
```

### 基本操作
1. **选择文件夹**: 点击按钮或拖拽文件夹
2. **扫描文件**: 按F5或点击扫描按钮
3. **预览结果**: 按Ctrl+P查看预览
4. **执行重命名**: 按Ctrl+R执行操作

- `Ctrl+Y`: 重做操作
