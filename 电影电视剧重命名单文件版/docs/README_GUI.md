
## 使用方法

### 1. 启动程序
```bash
python tv_rename_gui.py
```

### 2. 选择文件夹
- 点击"选择文件夹"按钮
- 选择包含影视文件的目录

### 3. 选择操作模式
- **预览模式**: 仅显示重命名建议，不执行实际重命名
- **实际重命名**: 执行实际的文件重命名操作

### 4. 扫描分析
- 点击"扫描并分析"按钮
- 程序会自动分析文件夹中的影视文件
- 在表格中显示分析结果

### 5. 执行重命名
- 在预览模式下检查重命名建议
- 切换到实际重命名模式
- 点击"执行重命名"按钮
- 确认操作后开始重命名

## 界面组件说明

### 控制面板 (ControlPanel)
- **文件夹选择**: 选择要处理的影视文件夹
- **操作模式**: 切换预览/重命名模式
- **操作按钮**: 扫描分析和执行重命名
- **进度条**: 显示操作进度

### 文件表格 (FileTableWidget)
- **原文件名**: 文件的原始名称
- **类型**: 识别出的文件类型（电影/电视剧）
- **标题**: 提取的影视标题
- **季**: 电视剧季数
- **集**: 电视剧集数
- **年份**: 发行年份
- **建议新名**: 建议的新文件名

## 架构说明

### 多线程设计
```python
class ScanWorker(QThread):
    """扫描工作线程"""
    progress_updated = pyqtSignal(int)
    scan_completed = pyqtSignal(list)
    error_occurred = pyqtSignal(str)

class RenameWorker(QThread):
    """重命名工作线程"""
    rename_completed = pyqtSignal(bool, str)
```

### 组件化结构
- **ScanWorker**: 处理文件扫描和分析
- **RenameWorker**: 处理文件重命名操作
- **FileTableWidget**: 显示文件信息表格
- **ControlPanel**: 提供用户控制界面
- **RenameUI**: 主界面协调器

### 信号槽机制
- 使用PyQt5的信号槽进行组件间通信

- 清晰的事件处理流程
