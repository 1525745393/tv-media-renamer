# 影视文件重命名工具 v1.3 智能分析版 使用说明

## 🚀 快速启动

### Windows用户

## 🎯 主要功能

### 1. 智能文件分析 🔍
- **快捷键**: `Ctrl+A`
- **功能**: 智能分析文件内容、分类和批量操作
- **特点**: 
  - 自动识别电影/电视剧/特辑/动画/纪录片
  - 提取标题、年份、季数、集数、质量信息
  - 置信度评分和智能建议
  - 批量分类处理
  - 多标签分类系统

### 2. 批量重命名 📝
- **快捷键**: `Ctrl+R`
- **功能**: 批量重命名文件
- **特点**:
  - 支持预览模式
  - 撤销/重做操作
  - 实时进度监控
  - 智能错误处理
  - 选择性重命名

### 3. 拖拽支持 🖱️
- **功能**: 直接拖拽文件到窗口
- **支持**: 单个文件或整个文件夹
- **特点**: 自动扫描和分类

### 4. 搜索和筛选 🔎
- **快捷键**: `Ctrl+F` (搜索)
- **功能**: 按文件名、类型、大小筛选文件
- **特点**: 实时搜索，支持正则表达式

### 5. 文件保护 🛡️
- **功能**: 智能文件保护机制
- **特点**:
  - 系统文件保护
  - 权限检查
  - 重复文件检测
  - 路径有效性验证

## 🎨 界面功能

### 主界面布局
- **左侧**: 控制面板（文件夹选择、操作按钮、状态信息）

- **统计报告标签页**: 显示分析统计信息（文件类型分布、置信度统计等）

- **重命名规则**: 自定义重命名格式
- **分类规则**: 自定义分类规则
- **性能设置**: 线程数、缓存设置、日志级别

## 📁 支持的文件格式

### 视频文件
- **常见格式**: `.mp4`, `.mkv`, `.avi`, `.mov`, `.wmv`, `.flv`, `.webm`
- **高清格式**: 支持4K、1080p、720p、480p等分辨率
- **编码格式**: 支持x264、x265、HEVC、AVC等编码

### 字幕文件
- **SRT格式**: `.srt` (SubRip字幕)
- **ASS格式**: `.ass` (Advanced SubStation Alpha)
- **SSA格式**: `.ssa` (SubStation Alpha)
- **SUB格式**: `.sub` (MicroDVD字幕)

### 其他文件
- **信息文件**: `.nfo` (媒体信息文件)
- **图片文件**: `.jpg`, `.png`, `.bmp` (封面图片)
- **文本文件**: `.txt` (说明文件)

## 🔧 故障排除

### 常见问题

1. **程序无法启动**
   - 检查Python版本（需要3.8+）
   - 检查PyQt5是否安装：`pip install PyQt5`
   - 检查依赖包是否完整：`pip install -r requirements.txt`
   - 检查系统权限

2. **文件分析失败**
   - 检查文件权限（确保有读取权限）
   - 检查文件格式是否支持
   - 检查文件是否损坏
   - 查看错误日志获取详细信息

3. **重命名失败**
   - 检查目标路径权限（确保有写入权限）
   - 检查磁盘空间是否充足
   - 检查文件名冲突
   - 检查文件是否被其他程序占用

4. **智能分析无结果**
   - 检查文件名格式是否符合标准
   - 尝试手动调整分类规则
   - 检查文件是否包含足够的信息
   - 查看置信度评分
