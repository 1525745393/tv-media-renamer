## 运行方式

从项目根目录（`电影电视剧重命名单文件版/`）运行：

```bash
# 完整版 GUI
python3 main/tv_rename_gui_v1.3.py

# 解析引擎测试
env PYTHONPATH=. python3 tests/test_media_renamer.py
python3 tests/test_all_features.py

# 工具脚本（相对路径基于项目根）
python3 scripts/tools/test_fix_verification.py
python3 scripts/tools/quick_scan_test.py
```

## 说明

- **入口版本**：代码实际只有 v1.3 入口（`main/tv_rename_gui_v1.3.py`）；`docs/` 中的 README_v1.4.md 为文档遗留，尚未有对应 v1.4 代码。
- **单文件版**：顶层 `tv_rename_gui.py` 依赖同级的 `core/tv_rename_cache_optimized.py` 与 `constants.py`（当前不完整，无法独立运行）。
- **解析引擎**（`core/tv_rename_cache_optimized.py`）已于 2026-09-21 完成原因级修复：标题/年份/季集识别 16 个典型用例全部正确，全功能测试 6/6 通过。
- **空壳文件**：根目录原 `workers.py`（1 字节）已移入 `.backups/workers.py.empty` 留档；真实模块在 `modules/workers.py`。
