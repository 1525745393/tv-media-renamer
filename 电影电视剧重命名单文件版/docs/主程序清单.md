# 影视文件重命名工具 - 主程序清单

## 📋 主程序文件总览

项目中包含以下可以独立运行的主程序文件：

### 1. 🎯 主要GUI程序

#### `tv_rename_gui_v1.3.py` - **推荐主程序**
- **功能**: 完整的GUI界面程序（已融合v1.4功能）
- **特点**: 
  - 智能文件分析
  - 批量重命名
  - 拖拽支持
  - 撤销/重做功能
  - 主题切换
  - 依赖检查
  - 详细日志系统
  - 错误处理增强
- **启动方式**: `python tv_rename_gui_v1.3.py`
- **状态**: ✅ **推荐使用（功能最完整）**

#### `tv_rename_gui_v1.4.py` - 增强版GUI程序
- **功能**: 与v1.3相同，但包含依赖检查
- **特点**: 
  - 启动时检查所有依赖模块
  - 更详细的错误处理
  - 更完整的日志系统
- **启动方式**: `python tv_rename_gui_v1.4.py`
- **状态**: ✅ **可用**

#### `main.py` - 简化版GUI程序
- **功能**: 与v1.4相同的GUI程序
- **特点**: 
  - 文件名简单，便于导入
  - 包含依赖检查
- **启动方式**: `python main.py`
- **状态**: ✅ **可用**
