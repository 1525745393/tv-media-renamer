# 影视文件重命名工具 v1.3 智能分析版

## 📋 项目概述

这是一个基于PyQt5的现代化GUI界面，用于影视文件重命名工具。采用模块化设计，提供流畅的用户体验和稳定的性能。v1.3版本修复了所有已知错误，增强了智能分析功能，提供了完整的文件管理和批量操作能力。

## ✨ 主要特性

### 🎨 现代化界面设计
- 响应式布局，支持窗口大小调整
- 美观的样式表设计（支持深色/浅色主题）
- 直观的操作流程
- 实时进度显示和状态更新

### ⚡ 高性能架构
- 多线程处理，避免UI阻塞
- 智能缓存机制，提高处理速度
- 批量文件处理，支持大量文件
- 内存使用优化，防止内存溢出

### 🛡️ 安全可靠
- 操作确认机制，防止误操作
- 错误恢复功能，自动处理异常
- 详细的操作日志，便于问题追踪
- 文件保护机制，保护重要文件

### 🔧 智能功能
- **智能文件识别和分析**: 自动识别电影、电视剧、动画、纪录片等
- **多标签分类系统**: 支持主分类、次分类和标签
- **置信度评分**: 智能评分和建议系统
- **批量重命名操作**: 支持选择性重命名
- **拖拽文件支持**: 直观的文件拖拽操作
- **撤销/重做功能**: 多级操作历史管理
- **操作历史记录**: 完整的操作记录和恢复

### 🔍 智能分析功能
- **文件类型识别**: 自动识别电影、电视剧、特辑、动画、纪录片等
- **信息提取**: 提取标题、年份、季数、集数、质量、编码等信息
- **置信度评估**: 为每个分析结果提供置信度评分
- **智能建议**: 基于分析结果提供重命名建议
- **批量分类**: 支持批量文件分类处理

## 🚀 快速开始

### 环境要求
- **Python**: 3.8 或更高版本
- **操作系统**: Windows 10+, Linux, macOS
- **依赖包**: PyQt5, 其他依赖见 requirements.txt

### 安装依赖
```bash
# 安装所有依赖包
pip install -r requirements.txt

# 或者单独安装PyQt5
pip install PyQt5
```

### 启动程序

#### Windows
```bash

# 方法2: 使用启动脚本
```

```bash
./启动程序.sh
```

## 🎮 使用指南

### 1. 选择文件夹
- 点击"选择文件夹"按钮或使用快捷键 `Ctrl+O`
- 选择包含影视文件的目录
- 支持拖拽文件夹到程序窗口

### 2. 智能分析
- 点击"智能分析"按钮或使用快捷键 `Ctrl+A`
- 程序会自动分析文件夹中的影视文件
- 在智能分析对话框中查看详细结果

### 3. 批量操作
- 在智能分析对话框中查看分析结果
- 使用批量操作标签页管理重命名和移动操作
- 支持选择性操作和批量处理

### 4. 执行重命名
- 在预览模式下检查重命名建议
- 切换到实际重命名模式
- 点击"执行重命名"按钮或使用快捷键 `Ctrl+R`
- 确认操作后开始重命名

## 🔧 功能模块

### 主窗口 (RenameUI)
- 协调所有组件和模块
- 处理用户交互和事件
- 管理应用程序状态和生命周期
- 提供统一的错误处理机制

### 工作线程 (Workers)
- **ScanWorker**: 处理文件扫描和分析，支持并行处理
- **RenameWorker**: 处理文件重命名操作，支持批量处理
- **SmartAnalysisWorker**: 处理智能分析任务

### 文件分析 (EnhancedAnalyzer)
- 智能识别文件类型（电影、电视剧、动画、纪录片等）
- 提取影视信息（标题、年份、季数、集数、质量、编码等）
- 生成重命名建议和置信度评分
- 支持多种文件命名格式

### 文件分类 (FileClassifier)
- 多标签分类系统
- 主分类和次分类支持
- 置信度评估
- 自定义分类规则

### 批量管理 (BatchManager)
- 批量操作管理和队列处理
- 操作进度跟踪和状态管理
- 选择性操作支持
- 操作历史记录

### 文件保护 (FileProtector)
- 文件备份和恢复机制
- 操作安全检查和验证
- 错误恢复和回滚功能
- 系统文件保护

### 操作历史 (OperationHistory)
- 完整的操作记录和查询
- 撤销/重做功能支持
- 历史备份和恢复
- 操作统计和分析

### 智能分析对话框 (SmartAnalysisDialog)
- 文件分析结果展示
- 分类结果管理
- 批量操作界面
- 统计报告生成

### 诊断工具 (DiagnosticTools)
- **问题检查**: 检查导入、语法、依赖、文件完整性
- **完整性测试**: 验证所有模块的导入和基本功能
