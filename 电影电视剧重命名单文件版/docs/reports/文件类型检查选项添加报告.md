# 文件类型检查选项添加报告

## 📋 功能概述

成功为UI设置界面添加了电影和电视剧检查选项，让用户可以精确控制扫描时处理哪些类型的文件。

## ✅ 新增功能

### 🎬 文件类型检查选项

在"文件类型"选项卡中添加了以下选项：

1. **检查电影文件** (`enable_movie_check`)
   - 默认值：`True`
   - 功能：启用后会在扫描时识别和处理电影文件
   - 工具提示：启用后会在扫描时识别和处理电影文件

2. **检查电视剧文件** (`enable_tv_check`)
   - 默认值：`True`
   - 功能：启用后会在扫描时识别和处理电视剧文件
   - 工具提示：启用后会在扫描时识别和处理电视剧文件

3. **检查特辑文件** (`enable_special_check`)
   - 默认值：`True`
   - 功能：启用后会在扫描时识别和处理特辑文件
   - 工具提示：启用后会在扫描时识别和处理特辑文件

### 🔧 强制规则选项

4. **强制应用电影命名规则** (`force_movie_rules`)
   - 默认值：`False`
   - 功能：启用后会强制将文件按电影规则处理，忽略其他识别结果
   - 工具提示：启用后会强制将文件按电影规则处理，忽略其他识别结果

5. **强制应用电视剧命名规则** (`force_tv_rules`)
   - 默认值：`False`
   - 功能：启用后会强制将文件按电视剧规则处理，忽略其他识别结果
   - 工具提示：启用后会强制将文件按电视剧规则处理，忽略其他识别结果

## 🔧 技术实现

### 1. UI界面修改

**文件位置**：`ui/settings_dialog.py`

- 在`_create_file_types_tab()`方法中添加了文件类型检查选项组
- 在`_load_settings()`方法中添加了选项加载逻辑
- 在`get_settings()`方法中添加了选项保存逻辑

### 2. 默认设置更新

**文件位置**：`core/constants.py`

```python
# 文件类型检查选项
"enable_movie_check": True,  # 检查电影文件
"enable_tv_check": True,     # 检查电视剧文件
"enable_special_check": True, # 检查特辑文件
"force_movie_rules": False,   # 强制应用电影命名规则
"force_tv_rules": False,      # 强制应用电视剧命名规则
```

### 3. 扫描逻辑修改

**文件位置**：`modules/workers.py`

在`analyze_single_file()`方法中添加了文件类型检查逻辑：

```python
# 检查文件类型检查选项
file_type = result.get('type', '')

# 根据设置决定是否处理特定类型的文件
if file_type == 'movie' and not self.settings.get('enable_movie_check', True):
    return None
elif file_type == 'tv' and not self.settings.get('enable_tv_check', True):
    return None
elif file_type == 'special' and not self.settings.get('enable_special_check', True):
    return None

# 强制应用规则
if self.settings.get('force_movie_rules', False):
    result['type'] = 'movie'
elif self.settings.get('force_tv_rules', False):
    result['type'] = 'tv'
```

## 🎯 使用场景

### 1. 选择性处理
- **只处理电影**：当用户只想整理电影文件时
- **只处理电视剧**：当用户只想整理电视剧文件时
- **混合处理**：当用户想同时处理多种类型时

### 2. 强制规则应用
- **强制电影规则**：当文件夹中的文件命名不规范，但用户知道都是电影时
- **强制电视剧规则**：当文件夹中的文件命名不规范，但用户知道都是电视剧时
