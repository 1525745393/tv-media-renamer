# 重命名格式修复报告

## 📋 问题概述

用户反馈重命名格式不正确，期望的格式是：
- **期望格式**: `三生有幸遇上你.S01.E40.mp4`
- **实际格式**: `三生有幸遇上你 [.S01.E01.mp4`

## 🔍 问题分析

### 1. **标题提取问题**
- **问题**: 从文件夹名称 `三生有幸遇上你 [2021]` 提取标题时，保留了方括号 `[`
- **原因**: 年份提取逻辑先提取年份，再清理标题，导致方括号残留

### 2. **集数识别问题**
- **问题**: 显示为 `E01` 而不是 `E40`
- **原因**: 实际文件名是 `EP01`，程序正确识别为集数 `1`

## 🔧 修复方案

### 1. **标题提取逻辑优化**

**修复前**:
```python
# 先提取年份，再清理标题
year_match = self._compiled_patterns['movie_year'].search(text)
if year_match:
    title = text[:year_match.start()].strip()  # 得到 "三生有幸遇上你 ["
# 然后清理标题...
```

**修复后**:
```python
# 先清理标题中的年份信息，再提取标题
clean_text = re.sub(r'\s*\[\s*\d{4}\s*\]\s*', '', text)  # 移除 [2021] 格式
clean_text = re.sub(r'\s*\(\s*\d{4}\s*\)\s*', '', clean_text)  # 移除 (2021) 格式
clean_text = re.sub(r'\s*\.\s*\d{4}\s*', '', clean_text)       # 移除 .2021 格式
title = clean_text.strip()  # 得到 "三生有幸遇上你"
```

### 2. **支持的年份格式**

修复后的代码支持以下年份格式的清理：
- `[2021]` - 方括号格式
- `(2021)` - 圆括号格式  
- `.2021` - 点号格式
