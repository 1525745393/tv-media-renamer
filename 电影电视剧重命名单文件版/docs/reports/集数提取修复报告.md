# 集数提取修复报告

## 📋 问题概述

根据日志分析，程序在处理大量文件时遇到了集数提取失败的问题，主要表现为：

1. **EP格式文件**：如 `Accidentally.Meow.On.You.2022.EP01.HD1080P.X264.AAC.Mandarin.CHS.BDYS.mp4`
2. **纯数字格式文件**：如 `01.mp4`、`1.mp4`、`10.mp4`
3. **标题+数字格式文件**：如 `步步惊心 01.mp4`、`宝莲灯前传 42.mp4`

错误信息：`未能提取到集数，跳过: [文件名] (未找到匹配模式)`

## 🔧 修复方案

### 1. 新增正则表达式模式

在 `PatternRecognizer` 类的 `__init__` 方法中添加了新的预编译正则表达式：

```python
# 新增：纯数字集数模式（支持01.mp4、1.mp4等格式）
'tv_episode_number_only': re.compile(r'^(\d{1,2})\.(mp4|mkv|avi|mov|wmv|flv|webm)$', re.IGNORECASE),
'tv_episode_number_with_title': re.compile(r'^(.+?)[ ._](\d{1,2})\.(mp4|mkv|avi|mov|wmv|flv|webm)$', re.IGNORECASE),
```

### 2. 更新tv_patterns字典

在 `tv_patterns` 字典中添加了对应的模式：

```python
# 新增：纯数字集数模式
'episode_number_only': re.compile(r'^(\d{1,2})\.(mp4|mkv|avi|mov|wmv|flv|webm)$', re.IGNORECASE),
'episode_number_with_title': re.compile(r'^(.+?)[ ._](\d{1,2})\.(mp4|mkv|avi|mov|wmv|flv|webm)$', re.IGNORECASE)
```

### 3. 增强extract_season_episode_optimized方法

在 `extract_season_episode_optimized` 方法中添加了对新模式的处理：

```python
# 新增：纯数字集数模式（01.mp4、1.mp4等）
episode_number_only_match = self._compiled_patterns['tv_episode_number_only'].search(filename)
if episode_number_only_match:
    episode = int(episode_number_only_match.group(1))
    if 1 <= episode <= 99:
        return None, episode, "纯数字集数模式"

# 新增：标题+数字集数模式（步步惊心 01.mp4等）
episode_number_with_title_match = self._compiled_patterns['tv_episode_number_with_title'].search(filename)
if episode_number_with_title_match:
    episode = int(episode_number_with_title_match.group(2))
    if 1 <= episode <= 99:
        return None, episode, "标题+数字集数模式"
```
