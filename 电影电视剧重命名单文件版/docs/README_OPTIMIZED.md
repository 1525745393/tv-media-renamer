# 影视文件重命名工具 - 优化版本 v1.4

## 🚀 新增优化功能

### 1. 拖拽支持
- **功能**: 支持直接拖拽文件或文件夹到程序窗口
- **使用方法**: 将媒体文件或包含媒体文件的文件夹拖拽到程序窗口
- **优势**: 快速添加文件，无需手动选择文件夹

### 2. 快捷键支持
- **Ctrl+O**: 选择文件夹
- **F5**: 扫描文件夹
- **Ctrl+R**: 执行重命名
- **Ctrl+P**: 批量预览
- **Ctrl+S**: 打开设置
- **F1**: 打开帮助
- **Ctrl+Q**: 退出程序
- **Escape**: 取消操作
- **Ctrl+F**: 聚焦搜索框
- **Ctrl+L**: 清除筛选
- **Ctrl+T**: 切换主题
- **Ctrl+Z**: 撤销操作
- **Ctrl+Y**: 重做操作

### 3. 智能缓存系统
- **文件分析缓存**: 缓存文件分析结果，避免重复分析
- **自动失效**: 基于文件修改时间和大小自动失效过期缓存
- **性能提升**: 大幅提升重复扫描的性能

### 4. 并行处理优化
- **多线程扫描**: 使用ThreadPoolExecutor进行并行文件分析
- **可配置线程数**: 通过设置调整最大工作线程数
- **进度显示**: 实时显示处理进度和预计剩余时间

### 5. 操作历史记录
- **撤销/重做**: 支持撤销和重做文件操作
- **操作备份**: 自动备份文件，确保操作安全
- **历史管理**: 限制历史记录数量，自动清理过期备份

### 6. 文件保护系统
- **安全检查**: 检查文件是否受保护（系统文件、隐藏文件等）
- **权限验证**: 验证文件读写权限
- **磁盘空间检查**: 检查磁盘空间是否充足
- **文件完整性验证**: 验证文件是否可读

### 7. 性能监控
- **操作计时**: 记录各种操作的耗时
- **性能报告**: 生成详细的性能统计报告
- **内存监控**: 实时监控内存使用情况

### 8. 增强的用户体验
- **实时预览**: 在文件表格中实时显示重命名预览
- **批量操作**: 支持选择性重命名
- **主题系统**: 支持浅色和深色主题切换
- **响应式布局**: 支持窗口大小自适应

## ⚙️ 配置选项

### 性能配置
```python
"parallel_processing": True,      # 启用并行处理
"max_workers": 4,                 # 最大工作线程数
"cache_ttl": 3600,               # 缓存有效期（秒）
"memory_limit": 1073741824,      # 最大内存使用限制（字节）
```

### 安全配置
```python
"backup_enabled": True,          # 启用备份功能
"backup_dir": ".backups",        # 备份目录
"max_backup_size_mb": 1000,      # 最大备份大小（MB）
"protected_extensions": [".exe", ".dll", ".sys"],  # 受保护的文件扩展名
```

### 历史记录配置
```python
"enable_history": True,          # 启用历史记录
"max_history": 100,              # 最大历史记录数
"skip_existing": True,           # 跳过已存在的文件
"enable_hash_check": False,      # 启用哈希检查
```

## 🐛 故障排除

### 常见问题
1. **扫描速度慢**: 检查是否启用了并行处理，调整max_workers参数
2. **内存使用高**: 检查memory_limit设置，清理过期缓存
3. **权限错误**: 确保对目标文件夹有读写权限
4. **磁盘空间不足**: 检查磁盘空间，清理备份文件

### 性能调优
1. **增加线程数**: 在设置中增加max_workers值
2. **调整缓存**: 根据文件数量调整cache_ttl
3. **清理缓存**: 定期清理过期的缓存文件
4. **优化扫描**: 使用更精确的文件过滤规则
