# 影视文件重命名工具 v1.4 - 智能分析版

## 🎉 版本亮点

v1.4版本带来了革命性的智能分析功能，让文件管理变得更加智能和高效！

### 🧠 核心新功能

#### 1. 智能文件分析器
- **深度解析**: 自动识别文件名中的标题、年份、季集、质量、编码等信息
- **置信度评分**: 为每个分析结果提供置信度评分，帮助用户判断准确性
- **改进建议**: 自动提供文件名优化建议
- **批量分析**: 支持大量文件的快速批量分析

#### 2. 智能文件分类器
- **自动分类**: 将文件自动归类为电影、电视剧、动画、纪录片、综艺、音乐等
- **多级分类**: 支持主分类和次分类
- **标签提取**: 自动提取质量、语言、编码等标签
- **组织建议**: 提供智能的文件组织建议

#### 3. 批量操作管理器
- **多种操作**: 支持重命名、移动、复制、删除等批量操作
- **队列管理**: 操作队列管理，支持暂停/恢复/取消
- **进度监控**: 实时显示操作进度和统计信息
- **错误处理**: 完善的错误处理和重试机制

#### 4. 智能分析对话框
- **多标签界面**: 分析结果、分类结果、批量操作、统计报告四个标签页
- **可视化展示**: 表格形式展示分析结果，支持颜色编码
- **交互操作**: 支持查看文件详情、添加批量操作等
- **结果导出**: 支持将分析结果导出为JSON格式

## 🚀 使用方法

### 基本操作流程

1. **启动程序**: 运行 `main_window.py`
2. **选择文件夹**: 点击"选择文件夹"按钮或使用 `Ctrl+O`
3. **扫描文件**: 点击"扫描"按钮或使用 `F5`
4. **智能分析**: 点击"🧠 智能分析"按钮或使用 `Ctrl+A`
5. **查看结果**: 在智能分析对话框中查看详细结果
6. **执行操作**: 根据需要添加批量操作并执行

## ⚙️ 配置文件

### custom_rules.json
自定义识别规则配置文件：
```json
{
  "title_patterns": ["\\b(电影|Movie|Film)\\b"],
  "exclude_patterns": ["\\b(sample|trailer)\\b"],
  "quality_weights": {"4K": 1.0, "1080p": 0.8},
  "language_weights": {"中文": 1.0, "英文": 0.8}
}
```

### classification_rules.json
分类规则配置文件：
```json
{
  "category_patterns": {
    "电影": {
      "patterns": ["\\b(电影|Movie|Film)\\b"],
      "exclude_patterns": ["[Ss]\\d{1,2}[Ee]\\d{1,2}"]
    }
  }
}
```

## 🐛 故障排除

### 常见问题

1. **智能分析速度慢**
   - 检查是否启用了并行处理
   - 调整max_workers参数
   - 清理过期缓存

2. **分类准确率低**
   - 检查custom_rules.json配置
   - 调整分类规则
   - 查看置信度评分

3. **批量操作失败**
   - 检查文件权限
   - 确认磁盘空间充足
   - 查看错误日志

### 性能调优

1. **增加分析速度**
   - 增加max_workers值
   - 调整cache_ttl参数
   - 使用SSD存储

2. **提高分类准确率**
   - 自定义分类规则
   - 调整权重设置
   - 添加特定模式

3. **优化内存使用**
   - 调整memory_limit设置
   - 定期清理缓存
   - 分批处理大文件
